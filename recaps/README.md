# Project Recaps

This file is the single central recap for every completed topic in this repository. Each section links directly to its matching folder inside leetcode, and breaks down what was learned, why those problems were chosen, where the pattern applies in real interviews, and how to prioritize revision time, both for opportunities within Kenya and worldwide.

## 1. Array Folder

Folder link: [leetcode/array](../leetcode/array)

### Coverage

* Twenty five problems in total
* Spans traversal, two pointer manipulation, prefix sums, sorting based approaches, and hash based tracking

### Key Patterns Learned

* Hash map and hash set lookups, from Two Sum and Contains Duplicate, trading memory for faster checks
* Two pointer manipulation, from Remove Duplicates from Sorted Array, Remove Element, Move Zeroes, Container With Most Water, Trapping Rain Water, and Rotate Array
* Binary search, from Search Insert Position and Search in Rotated Sorted Array, including on arrays that are no longer fully sorted
* Single pass running value tracking, from Best Time to Buy and Sell Stock, Single Number, and Majority Element
* Index and value relationships to avoid extra memory, from Missing Number and Find All Numbers Disappeared in an Array
* Kadane's algorithm, from Maximum Subarray, one of the most frequently asked array questions industry wide
* Prefix and suffix products, from Product of Array Except Self, avoiding the obvious but disallowed division approach
* Sorting combined with two pointers, from 3Sum and Merge Intervals
* Hash based thinking over brute force, from Longest Consecutive Sequence and Subarray Sum Equals K

### Where This Applies in Interviews

* Two Sum and Contains Duplicate, common in nearly every phone screen or online assessment worldwide
* Container With Most Water and Trapping Rain Water, common at Google and Meta
* Product of Array Except Self, a strong signal question at Microsoft and Amazon
* Merge Intervals, common at companies building scheduling or logistics systems

### Preparing in Kenya and Worldwide

* Very few companies hiring directly within Kenya run strict algorithmic interviews of this style
* Local hiring tends to weigh practical coding ability and system understanding more heavily
* This preparation matters most as a gateway into remote roles at international companies
* It also applies directly to global hiring platforms, where the interview format matches what any candidate elsewhere in the world would face

### Priority List if Time is Limited

* Two Sum
* Maximum Subarray
* Container With Most Water
* 3Sum
* Search in Rotated Sorted Array
* Subarray Sum Equals K


## 2. Two Pointers Folder

Folder link: [leetcode/two_pointers](../leetcode/two_pointers)

### Coverage

* Fourteen problems in total
* Spans string comparison, sorted array searching, in place partitioning, interval overlap, backward scanning, greedy pairing, permutation generation, sliding window technique, and fast and slow pointer cycle detection

### Key Patterns Learned

* Inward pointer comparison on strings, from Valid Palindrome and Valid Palindrome II
* Narrowing on a sorted array toward a target, from Two Sum II
* Closest sum tracking instead of exact matching, from 3Sum Closest
* Three way in place partitioning, from Sort Colors
* Comparing magnitude from both ends and filling backward, from Squares of a Sorted Array
* Greedy pairing of extremes, from Boats to Save People
* At most two occurrences in place filtering, from Remove Duplicates from Sorted Array II
* Extending a three number pattern to four, from 4Sum
* Comparing two separate sorted lists simultaneously, from Interval List Intersections
* Backward scanning with pending deletion tracking, from Backspace String Compare
* Grouping based on last occurrence, from Partition Labels
* Careful in place rearrangement into the next ordering, from Next Permutation
* Sliding window expansion and shrinking with frequency tracking, from Minimum Window Substring
* Fast and slow pointer cycle detection, from Linked List Cycle

### Where This Applies in Interviews

* Two Sum II and Valid Palindrome are common warm up questions testing clean pointer logic
* Minimum Window Substring is considered one of the hardest and most respected string problems industry wide
* Linked List Cycle is a staple at nearly every company that tests linked list fundamentals
* Sort Colors and Next Permutation are common at companies testing careful in place manipulation under constraints

### Preparing in Kenya and Worldwide

* The same gap applies here as with arrays, very few companies hiring directly within Kenya run strict algorithmic interviews of this style
* This preparation remains most valuable as a gateway into remote roles at international companies and global hiring platforms
* The underlying patterns, pairing, shrinking, and cycle detection, also map directly onto practical systems in fintech, healthtech, logistics, and ride hailing platforms, not just interview settings

### Priority List if Time is Limited

* Two Sum II
* Valid Palindrome
* Minimum Window Substring
* Linked List Cycle
* Next Permutation
